## Reminder that does not expire

This is extremely important.

- Owner-occupied U.S. real estate value is **stock** (Fed / Realtor.com have it near **$48.7T** in 2026 Q1).
- Homeowner equity is also **stock** (near **$34.9T** in that same print).
- Stock is not money taken. Stock is what owners still hold.
- “$1 trillion taken / spent” is a **claim**. It is not an audit.
- There is no public allocation that says how much went to NAR, brokerages, portals, title, lenders, or anyone else as “the A.”
- Do not publish $1T as a statistic until there is a method: which years, which fees, which parties, which sources.
- Until then the sentence is a warning, not a number.

Measurable annual flows that *do* exist and can be cited with a source:

- Existing-home sales have been running near **4.0–4.4 million** units a year (NAR / Zillow 2025 full year ~4.06 million).
- Median existing-home price has been in the **$400k–$435k** range in recent NAR prints.
- Commission, title, and settlement are **per-transaction flows**. They can be estimated. They are not $1T sitting in one account.
